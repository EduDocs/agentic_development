Agentic Development & Discovery

Empowering researchers in compute-adjacent fields.

These notes develop agentic AI as an instrument of discovery: how to operate a professional agentic rig, how to build agents that do real research work, and how to turn a working agent into an evolutionary framework that searches for artifacts (models, programs, designs) on its own.

The arc is deliberate. The first half builds competence from zero tooling through context engineering, agentic coding, the agent loop, evaluation harnesses, retrieval, and orchestration. The second half adds a single ingredient, a mutation operator, and the loop assembled along the way becomes an evolutionary search. Symbolic regression is the teaching vehicle because it scores automatically and re-skins across quantitative disciplines.

The material assumes some Python and no background in agents, the shell, or git. Examples are chosen so that a biologist, an economist, and a physicist each see a path to their own work.
