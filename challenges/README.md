# Challenges

The **core biweekly unit** (4). Each Challenge = reading + a structured, objectively-scored build
task + a code/report submission. Mix of individual and team. This is the modernized form of the
original "4 × 2-week projects"; the evolutionary half is taught at the pivot and practiced in the
capstone, not as a fifth Challenge (D-013).

**Anatomy:** `brief.md` · data/scaffold · `rubric.md` · submission template · objective score via
the shared eval-harness/leaderboard (see `../benchmarks/`).

*Each challenge folder holds a `brief.md` and a `rubric.md`.*
