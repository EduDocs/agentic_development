# Projects

The major **capstone** deliverable — a team (or individual) system applied to the student's
**own dissertation domain**, with a paper-style report (~8 pages, IEEE-style) + code on GitHub:
"build → evolve → write up" an agentic (ideally evolutionary) research system.

**Anatomy:** proposal template · milestone schedule · `rubric.md` (Project + Teamwork rubrics) ·
report template.
