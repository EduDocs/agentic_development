# Capstone Report — Template

> Paper-style, ~8 pages, IEEE-style. Markdown or LaTeX. The
> section headings below map to the [`rubric.md`](rubric.md) criteria.

## Title · Authors · Abstract
- **Abstract** (~150 words): problem, method, key result.

## 1. Introduction
- The domain problem; why model discovery; your contribution in one paragraph. *(→ Problem Formulation)*

## 2. Background & Related Work
- Domain priors / literature; the evolutionary lineage (FunSearch / AlphaEvolve / OpenEvolve). *(→ Originality)*

## 3. Data & Fitness
- The dataset and the held-out protocol; the **fitness function** and how it resists gaming. *(→ Method)*

## 4. Method
- Baselines; the **evolutionary loop** (artifact, mutation operator, population, diversity, cost);
  the proposal model(s). *(→ Method & Evolutionary Search)*

## 5. Results
- Evolved result vs. baselines on the leaderboard; **search dynamics**; cost. *(→ Analysis)*

## 6. Analysis & Limitations
- What worked, what didn't, what you'd do next. **Honest** failure analysis. *(→ Analysis, Originality)*

## 7. Reproducibility
- How to run it; where the code and lineage live. *(→ Presentation)*
